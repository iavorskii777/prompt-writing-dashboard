Подсказки

Чем точнее перечислены листы, поля и правила, тем лучше Gemini пишет код для Colab.

Для XLSX полезно требовать pandas или XlsxWriter.

Для JSON и YAML важно просить валидную структуру без поясняющего текста.

Для SQL указывайте СУБД и ожидаемые типы запросов.
